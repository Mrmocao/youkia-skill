# 正常使用与交付

## 从用户请求到一次生成

确认用户明确要求生成，而非只讨论提示词、开启功能或诊断。使用已连接的 MCP `imagine` 完成提交、等待和结果返回；先读取当前 schema。参数保留用户意图，未指定的设置维持默认，不额外增加 repeat、模型、stylize、chaos 或后处理任务。

将提示词中的 `--ar 16:9` 转为 `aspect: "16:9"`，正文仅保留画面描述。以下为参数示例，**阅读本指南不构成执行授权**：

```json
{
  "prompt": "一条可爱的锦鲤，细腻真实的鳞片，半透明柔软鱼鳍，在清澈水中优雅游动，柔和自然光，精致的电影级三维质感",
  "aspect": "16:9",
  "confirm": true,
  "save": true,
  "out_dir": "<ABSOLUTE_WRITABLE_OUTPUT_DIR>"
}
```

## 原图作为 Image Prompt

当前 2.0.1 的 `imagine.image_prompts` 接受直接图片 URL，包括带扩展名的图片 URL，以及 Midjourney 常见的 `https://s.mj.run/...`、`cdn.midjourney.com` 和 `storage.googleapis.com` 资源 URL。它不接受本地 `C:\...` 路径、网页详情页 URL 或未上传的附件对象；这类输入应在本地校验阶段被拒绝，避免付费提交。

“先在 MJ 上传原图，再粘贴”是网页人工操作流程，不是 MCP 自动上传能力。只有技能不代表同事的电脑已经配置 MCP。工具缺失时先走安装与只读验收，不自动退回电脑控制。若电脑控制报“无法可靠识别 Chrome 当前网址而被系统停止”，先停止并读取实际工具错误；只有转述时应说“疑似电脑控制通道问题”，不能断言其来源或账号状态。不得猜测 URL 或换通道重做被系统阻止的动作。独立的素材准备流程可让用户在本地浏览器手动上传，取得实际可访问的图片资源 URL；不保证网页一定提供 s.mj.run 形式的链接，不索取密码、Cookie 或 Token。

得到 URL 后，将它放入 `image_prompts`，主体描述放入 `prompt`，参数放入独立字段；不要把 URL 贴进普通提示词，也不要重复上传同一张原图。

MCP 确认表单出现后，由用户勾选 **Approve** 再批准。只有点击提交而没有勾选，仍会被拒绝。若客户端根本不支持表单，上游可能退回 confirm:true；此时不能把该参数当成人类审批的技术保证，必须已有明确的具体操作授权。不能为了让拒绝消失主动切换为这种回退。

一次任务常返回四张候选，不等于要提交四次；`repeat` 和批量提示词会增加任务与消费。变体、放大、重混、动画等都可能另行计费，不能当作免费的默认收尾自动运行。

## 跟踪和下载

- 普通单次任务优先 imagine；用户明确要异步、批量或较长 relax 任务时使用 submit_imagine，并保留任务 ID 交给 wait_for_job。
- 网络错误、等待超时或未返回 ID 时，先 get_queue、list_jobs、get_job 对照时间和提示词查找已接受的任务。先恢复已有任务，不盲目再次提交。
- 使用 save:true 或 download_job 保存实际原图，不把网页截图当成生成结果。确认输出目录可写，验证文件存在和格式后，用绝对文件路径在聊天显示图片。
- 用户要求参考风格时，moodboard 用对应风格板机制；单图风格参考用 style_refs，对象一致性用 omni_refs。按当前模型与 schema 核实支持，不把风格板采样图片假装成等价实现。
- 不固定“最新模型永远是某版本”，不承诺 seed 在不同版本或不同设置下严格复现。
- CLI 适用于用户明确要求的脚本化工作。先检查固定版本 CLI help；`--confirm` 会允许消费，不用于绕过 MCP 的取消、拒绝或自动审核阻止。
- 不将 api_get 或 submit_raw_job 作为普通错误的逃生通道；未知写入 payload 不能靠付费试错验证。

## 可直接提问的示例

- “用 Midjourney 检查连接和账号状态，先不要生成。”
- “启用 Midjourney 生成功能，但不要提交任务。”
- “用 Midjourney 生成一条可爱锦鲤，16:9，仅一个任务，保存原图。”
- “刚才没看到确认表单就被拒绝，请检查原因，不要重新生成。”
- “查询上次任务是否完成并下载结果，不要重复提交。”

交付说明包含：实际调用方式、任务状态、候选数量和文件位置。出现失败时区分本地校验、确认拒绝、网站验证、余额限制和网络错误；只报告已验证的原因。
