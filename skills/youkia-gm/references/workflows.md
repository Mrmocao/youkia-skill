# 特殊页面工作流

先查 `menus` 和相关页面定义，再查 `endpoints`、`api-schema`。以下为网页协议已确认的流程；实际写入尚未联调。

## 平台表单、审核、下发

1. 类型 3 菜单 `menu-schema` 返回 `table`、参数和组件。`menu-plan` 保存草稿记录，使用 `dyn_update`，不会直接发到游戏。
2. `/gm/gtable_port/dyn_list` 读取指定表中的记录及 `examine` 状态。`/gm/gtable_port/dyn_get` 使用 `table`、`dyn_uid`、`language` 读取预览。
3. `/gm/gtable_port/dyn_examine` 请求 `{"k":"实际table","v":记录UID}`。同一接口切换审核状态，不是幂等“设为已审核”。只有当前状态不同于用户期望时才需要调用。
4. `/gm/gtable_port/dyn_send` 请求 `list_tup4_str_int`，每条内容为 `{k:表名,v1:记录UID,v2:菜单UID}`。实际目标来自保存的记录，必须先回读记录中的服务器列表，不能认为 CLI 的当前服务器就是下发范围。`dyn_send_quick` 是另一条下发路径，不自动替换常规路径。
5. 平台返回任务 UID 后查原计划结果。逐服返回信息不能只合并为一个“成功”。

审核状态前提 `expected.json`：

```json
[
  {
    "endpoint": "/gm/gtable_port/dyn_list",
    "data": {"reply": "真实表名"},
    "path": ["list", {"uid": 123}, "examine"],
    "equals": false
  }
]
```

把 `123` 替换为查到的记录 UID。此结构通过 UID 定位，不依赖列表顺序。计划生成和执行前都会核对。取消审核则期望当前值为 `true`。下发或删除也建议增加记录状态及目标服务器前提，避免预检后记录改变。

## 活动管理

| 用途 | 接口尾部（前缀 `/gm/gactive_port/`） |
|---|---|
| 主模板、内容模板、时间模板读取 | `active_main_get`、`active_item_list`、`active_time_list` |
| 平台活动列表、预览 | `active_list`、`active_get` |
| 创建/修改、审核、删除 | `active_add`、`examine`、`active_delete` |
| 下发 | `active_send`、`active_send_quick` |
| 回收站查看、预览、恢复 | `active_recycle_list`、`active_recycle_get`、`active_recycle_revert` |

活动的 `json` 配置必须匹配该项目真实主模板、内容模板和时间模板。不能根据其他游戏活动配置猜字段。模板读接口中有 bytes 数据，需要解码后才能解释。

活动审核请求 `{"item":活动UID}`，状态前提使用 `active_list`、路径 `["list",{"uid":活动UID},"examine"]` 和实际当前布尔值。计划不会自动选择所有活动或所有服务器。

活动下发请求字段通过 `api-schema` 查看 `active_send_req`；必须使用用户明确的活动 UID 与服务器范围。下发请求的服务器列表可能与当前会话服务器不同，提交前以请求中的完整范围为准。

“平台活动列表”与“服务器正在运行的活动列表”不是同一数据源。后者属于普通 GM 查询菜单，会产生异步任务，不能把平台配置列表描述成服务器生效状态。

## 项目、用户、权限、语言及组件管理

这些接口已收录在协议快照，可通过 `api-plan` 构建请求。使用对应菜单和真实按钮权限；平台管理使用项目/版本 `0/0`，项目内管理使用实际项目/版本。

对新增账号、改密、锁定、权限修改、项目删除等操作，要求用户授权覆盖具体对象和行为，不从“检查”“扫描”“配置工具”推断授权。密码类请求在计划输出中遮蔽，原始值只留在加密计划中；包含敏感内容的输入文件由用户存放在受控目录，不加入包中。

未知业务规则、字段含义或按钮映射先回到对应网页定义或平台文档查证。禁止通过替换菜单/按钮键冒充授权。服务端拒绝时不切换高权限账号尝试。

## 结果验证与外链

`single_str` 返回 `ok` 能证明平台对本次请求的响应，不证明游戏收到或生效；记录修改通过列表/详情回读，任务下发通过任务结果和必要的业务查询验证。

外链菜单只报告地址和用途；不继承其任意命令或自动向外站传递 GM 凭据。本版不代理外链系统。
