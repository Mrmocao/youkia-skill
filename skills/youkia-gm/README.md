# youkia GM 助手 0.1.2

通过 Codex 的自然语言交互操作 youkia GM。包含可运行的协议客户端、动态表单校验、预检计划、提交记录和结果查询，不只是提示词模板。

支持 Windows 10/11 x64，随包提供官方 Python 3.14.8。启动时优先使用系统 Python 3.10+；缺失或不满足要求时，自动将包内 Python 部署到技能目录后继续。无需管理员权限、不修改系统 PATH、无需 pip 安装依赖。GM 操作需要能访问固定的平台地址。

## 安装与首次使用

推荐保留解压目录，在 Codex 中说：“读取 `E:\实际解压位置\youkia-gm\SKILL.md`，启动 youkia GM 并引导配置。”Codex 将调用该目录下的 `gm.ps1`，自动检查并准备 Python，缓存也保存在该目录的 `state`。后续继续从这个目录启动即可。

下方安装方式会复制代码到技能目录，缓存也将使用安装后的目录；不会迁移解压目录里已绑定的账号。如果希望缓存始终保留在原解压目录，直接采用上述启动方式。

将 `youkia-gm` 文件夹放到 Codex 技能目录；或在本文件夹运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1
```

安装脚本遇到同名技能会停止，不覆盖。不会启动 GM 操作，也不会修改已有 `gm-cli` 技能。安装后在新 Codex 会话中使用 `$youkia-gm`。

也可以不安装，直接执行本包脚本：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\gm.ps1 doctor
powershell -NoProfile -ExecutionPolicy Bypass -File .\gm.ps1 configure --username '你的账号'
powershell -NoProfile -ExecutionPolicy Bypass -File .\gm.ps1 projects
```

配置时隐藏输入密码。后续复用绑定账号，只有明确使用 `configure --replace` 才替换。不要将真实密码写入示例命令。

账号、会话、项目功能目录、预检计划、结果以及服务器缓存放在解压目录的 `state` 子目录，使用 Windows 当前用户加密。ZIP 分发包不保存这些内容；同一账号建议只使用一个状态目录。本地锁不能约束另一个工具或网页会话。

启动后由 Codex 按顺序引导：验证绑定账号密码 → 扫描可访问项目 → 询问目标项目/版本 → 提示并执行该项目的只读 GM 功能定义扫描 → 进入任务模式。更换账号后重新扫描项目和功能；切换项目后读取对应缓存，首次进入则扫描。

## 可以这样对 Codex 说

选服时可以一次说“后端/女妖_ai_797/1服，查询角色……”。Codex 验证并保存服务器后，直接接着处理这条任务；缺少角色等必要参数时只补问缺项。之后只说任务即可，一直沿用当前服务器，直到明确切换。选择保存在本包 `state`，再次启动会显示当前目标；不同账号、项目或版本不混用服务器。

例如：“切换到2服，查询角色……”会更新默认服；“仅这次查询2服……”或一次多服任务不会改变原默认服。已扫描的项目选服后只读取任务所需定义，不重新全量扫描。

- “看看这个账号能操作哪些游戏项目。”
- “在我指定的项目和测试服，查一下玩家查询菜单需要哪些参数。”
- “列出该项目后台已配置的活动，告诉我哪些已审核。”
- “按我给的目标和参数预检这次 GM 操作，说明会执行什么。”
- “执行刚才已经确认的计划，并告诉我每台服务器的返回结果。”

自然语言理解由 Codex 提供；脚本本身是结构化执行工具。用户明确操作范围后可直接执行；缺少目标或授权时先补齐。

环境来源与部署方式见 [Python 运行时说明](references/python-runtime.md)。包内 `assets` 是随包运行时，`runtime` 是本地自动部署目录；分发 ZIP 不包含已部署运行时与个人配置。

## 本版状态

已通过本地单元测试及真实 GM 只读验证，包括账号配置、会话复用、项目切换、动态组件和菜单预检。实际写操作尚未在 GM 测试服联调，不宣传为已实现 100% 网页替代。

当前快照收录 112 个接口：43 个只读接口、3 个会话上下文接口、66 个写接口。接口有定义不等于其业务流程全部完成实测。普通菜单有专门的参数/目标校验；专用页面使用协议级适配入口，仍需要理解页面业务规则。功能定义扫描结果会缓存到解压目录的 `state`，减少后续重复读取。

详细内容见 [命令说明](references/usage.md)、[特殊页面流程](references/workflows.md)和[功能覆盖表](references/coverage.md)。
