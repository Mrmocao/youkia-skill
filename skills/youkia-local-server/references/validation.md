## 验证边界

真实游戏环境没有执行停止 Play、停服、删除 db 或启动服务器。清档顺序和异常处理使用隔离目录及模拟后端验证；真实 Windows 启动调用使用无游戏副作用的临时 BAT。首次真实启停及清档仍需在用户明确下达对应任务后验收。

健康检查证明目标进程、节点登记和配置端口符合条件，不证明游戏登录、角色存档或业务功能已经完成验证。原游戏安装器和启动 BAT 仍属于外部程序，其内部行为不由本包重写。
