# 适配与验证边界

本版 0.1.0 面向 Windows x64、PowerShell 5.1 和 Jira Server REST v2，优先适配已检查的 Jira Server 9.4 站点。随包 Python 3.14.8 或系统 Python 3.12+，无第三方 Python 依赖。需网络可达和对应账号权限。

测试分为：本地模拟服务的真实 HTTP 请求及写入回读测试；Windows DPAPI 往返及原生窗口验证；真实站点的只读元数据/查询验证；解压与技能抽取后独立运行验证。打包期间不会向真实项目提交测试 Bug、备注、流转或附件。具体执行记录由发布说明列出，不能把模拟写入测试宣传为生产写操作验证。

创建字段采用 `/rest/api/2/issue/createmeta/{project}/issuetypes` 及分类型分页字段端点，不依赖已验证站点中不可用的旧聚合创建接口。其他版本不提供这些端点时应按需适配，不缓存旧字段作为替代。

Cloud、SSO/验证码、插件写接口、管理员操作、删除任务、跨站附件及自动游戏验收未作为开箱即用功能。敏捷资源可在权限允许时按需只读探测。报告是用户要求生成的有时间戳快照，查询本身不创建缓存。
